## System Information
- uname -a  
  ‣ Show kernel version and system architecture.
- cat /etc/os-release  
  ‣ Display Linux distribution information.
- hostnamectl  
  ‣ Show or set hostname and system metadata.
- lsb_release -a  
  ‣ Print distribution release details.
- uptime  
  ‣ Show system load and time since last boot.
- dmesg | tail  
  ‣ View recent kernel messages.

## Users & Groups
- id  
  ‣ Show current user’s UID, GID, and groups.
- whoami  
  ‣ Print the effective username.
- cat /etc/passwd  
  ‣ List system users.
- cat /etc/group  
  ‣ List system groups.
- groups USER  
  ‣ Show group memberships for a user.
- sudo -l  
  ‣ List allowed sudo commands.
- last / lastlog  
  ‣ Show login history.

## Processes & Services
- ps aux  
  ‣ List all running processes.
- ps -ef  
  ‣ Full-format process listing.
- top / htop  
  ‣ Real-time process monitoring.
- systemctl status SERVICE  
  ‣ Show service status.
- systemctl list-units --type=service  
  ‣ List all systemd services.
- journalctl -u SERVICE  
  ‣ View logs for a specific service.

## Networking
- ip a  
  ‣ Show network interfaces and IPs.
- ip r  
  ‣ Display routing table.
- ss -tulnp  
  ‣ Show listening ports and associated processes.
- netstat -ano  
  ‣ Legacy port and connection listing.
- arp -a  
  ‣ Show ARP cache.
- ping -c 4 HOST  
  ‣ Test connectivity.
- traceroute HOST  
  ‣ Trace network path to host.

## File System & Permissions
- ls -la  
  ‣ List files with permissions.
- stat FILE  
  ‣ Show detailed file metadata.
- find / -type f -name "*.conf" 2>/dev/null  
  ‣ Search for config files.
- df -h  
  ‣ Show disk usage.
- du -sh *  
  ‣ Show folder sizes.
- chmod / chown  
  ‣ Modify permissions and ownership.
- getfacl / setfacl  
  ‣ View or modify ACL permissions.

## Package Management
### Debian/Ubuntu
- apt update && apt upgrade  
  ‣ Update package lists and upgrade system.
- apt install PACKAGE  
  ‣ Install a package.
- dpkg -l  
  ‣ List installed packages.

### RHEL/CentOS
- yum install PACKAGE  
  ‣ Install a package.
- rpm -qa  
  ‣ List installed RPM packages.

## Logs
- /var/log/syslog  
  ‣ Main system log.
- /var/log/auth.log  
  ‣ Authentication and sudo logs.
- journalctl -xe  
  ‣ View recent systemd logs with errors.

## Useful Security Checks
- find / -perm -4000 2>/dev/null  
  ‣ Find SUID binaries.
- find / -writable -type d 2>/dev/null  
  ‣ Find world-writable directories.
- find / -name "*.bak" 2>/dev/null  
  ‣ Locate backup files.
