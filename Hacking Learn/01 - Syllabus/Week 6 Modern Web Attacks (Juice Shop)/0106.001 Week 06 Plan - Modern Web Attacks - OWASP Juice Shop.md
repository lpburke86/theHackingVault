# 1. Weekly Overview

Week 6 takes you into **OWASP Juice Shop**, one of the most modern, realistic, and intentionally vulnerable web applications ever created.

This week focuses on:

- Modern JavaScript/Node.js exploitation
- JWT manipulation
- NoSQL Injection
- Advanced XSS
- CORS misconfigurations
- File upload bypasses
- Business logic flaws
- API exploitation
- Race conditions

Juice Shop is where you transition from “classic web vulns” to **modern, real‑world attack surfaces**.

**Time:** 1.5 hours  
**Workbook:** [[0208.000 Juice Shop Workbook]] → Sections 4–5

```bash

```

### **Lab 2 — NoSQL Injection**

**Time:** 2 hours  
**Workbook:** [[0208.000 Juice Shop Workbook]] → NoSQLi Section

Payload:

```json
{"email":{"$ne":null},"password":{"$ne":null}}
```

Goal:

- Bypass login
- Enumerate users
- Extract data

---

### **Lab 3 — JWT Manipulation (alg=none + kid traversal)**

**Time:** 2 hours  
**Workbook:** [[0208.000 Juice Shop Workbook]] → JWT Section

Decode token:

```bash
jwt-tool -t <token>
```

Modify header:

```json
{"alg":"none","kid":"../../../../etc/passwd"}
```

Goal:

- Forge admin token
- Access restricted endpoints

---

### **Lab 4 — XSS + CORS + File Upload Bypass**
