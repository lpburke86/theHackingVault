# 1. Weekly Overview

Week 2 expands your reconnaissance and enumeration skills into **professional‑grade methodology**.  
You will learn how to:

- Identify services
- Fingerprint versions
- Enumerate SMB, FTP, SSH, HTTP, and databases
- Build a structured recon → enum → exploit workflow

This week is the bridge between “basic scanning” and “real pentesting.”

---

# 2. Learning Objectives

By the end of Week 2, you will be able to:

- Perform full‑spectrum enumeration on a target
- Identify high‑value services and attack surfaces
- Use NSE scripts effectively
- Enumerate SMB, FTP, SSH, HTTP, and MySQL
- Document findings using your templates
- Build a recon → enum → exploit hypothesis

# 4. Weekly Labs

### **Lab 1 — Full Service Enumeration on MS2**

**Time:** 1 hour  
**Workbook:** [[0202.000 Metasploitable 2 Workbook]] → Section 5

Commands:

```bash
nmap -sC -sV -oN ms2_enum.txt <MS2-IP>
```

---

### **Lab 2 — SMB Enumeration**

**Time:** 1 hour  
**Workbook:** [[0202.000 Metasploitable 2 Workbook]] → SMB Section

Commands:

```bash
smbclient -L //<MS2-IP>/ -N
enum4linux -a <MS2-IP>
```

---

### **Lab 3 — Web Enumeration**

**Time:** 1 hour  
**Workbook:** [[0202.000 Metasploitable 2 Workbook]] → Web Section

Commands:

```bash
gobuster dir -u http://<MS2-IP> -w /usr/share/wordlists/dirb/common.txt
curl -I http://<MS2-IP>
```

---

### **Lab 4 — Database Enumeration**

**Time:** 1 hour  
**Workbook:** [[0202.000 Metasploitable 2 Workbook]] → MySQL Section

Commands:

```bash
mysql -h <MS2-IP> -u root -p
nmap --script=mysql* -p 3306 <MS2-IP>
```

# 6. Mini‑Project

### **Mini‑Project — Build a Recon → Enum → Exploit Map**

**Time:** 1.5 hours  
**Output:** A new page in your vault:  
`[[0602 Attack Surface Map — MS2]]`

Include:

- All services
- All versions
- All potential vulnerabilities

- Notes on what to test next

This becomes your **first real attack plan**.

# 7. Instructor Notes

- Enumeration is where most students fall behind — stay disciplined
- Save ALL scan outputs in your vault
- Build the habit of naming files consistently
- Don’t jump to exploitation too early
- Your attack hypothesis is more important than your tools
