# **WEEK 03 — Web Foundations & Modern Web Communication**

### **Add: Burp Suite (Community Edition) — Foundations Lab**

**Purpose:** Introduce Burp as the student’s primary web traffic analysis tool.

**Lab: Burp Suite Interception & Traffic Analysis**

- Install Burp CA certificate
- Configure browser proxy
- Intercept HTTP/HTTPS traffic
- Observe request/response structure
- Identify cookies, headers, sessions
- Follow login flow end‑to‑end
- Map application structure using Proxy + Target

**Outcome:**  
Students understand how web traffic actually looks and behaves, and how Burp becomes the “microscope” for all future web exploitation.
