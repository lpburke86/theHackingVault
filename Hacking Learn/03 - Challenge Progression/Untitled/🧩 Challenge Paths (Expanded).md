
These optional tracks run parallel to the main curriculum. Each path is a **specialization** that builds mastery in a specific domain.

## **Path A — Web Exploitation Mastery**

For students who want to specialize in web security.

### **Progression:**

1. DVWA fundamentals
    
2. Mutillidae intermediate exploitation
    
3. WebGoat enterprise‑style exploitation
    
4. Juice Shop modern web attacks
    
5. 5 VulnHub web‑heavy machines
    
6. Build a personal payload library
    
7. Build a multi‑app chained exploit
    

### **Skills Gained:**

- SQLi (classic, blind, stacked)
    
- XSS (reflected, stored, DOM, Angular)
    
- JWT manipulation
    
- NoSQLi
    
- CORS exploitation
    
- File upload bypasses
    
- API exploitation
