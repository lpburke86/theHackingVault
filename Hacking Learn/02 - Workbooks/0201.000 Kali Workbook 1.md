# 1. Introduction to Kali Linux

## What Kali Is
- A Debian‑based penetration testing distribution  
- Maintained by Offensive Security  
- Includes 600+ security tools  
- Designed for offensive workflows, not general use  

## What Kali Is NOT
- Not a daily driver OS  
- Not inherently “hacky” — tools require skill  
- Not a magic button for exploitation  

## Why Kali Is Used in This Lab
- Standardization across machines  
- Preinstalled tools  
- Community support  
- Works seamlessly with Metasploitable, DVWA, VulnHub, AD labs

# 2. System Architecture & Internals

## File System Structure
- `/usr/share/` — tool installations  
- `/etc/` — configs  
- `/var/log/` — logs  
- `/opt/` — custom tools  
- `/home/kali/` — your workspace  

## Services
- SSH  
- Apache2  
- PostgreSQL (Metasploit)  

## Package Management
- `apt update && apt upgrade`  
- `apt install <tool>`  
- `apt remove <tool>`  

## Instructor Note  
Kali is just Debian with tools.  
The magic is in **workflow**, not the OS.

# 3. Lab Setup & Networking

## Network Modes
- **NAT** — internet access  
- **Host‑only** — isolated lab  
- **Bridged** — LAN access  

## Recommended Setup for This Course
- Kali: NAT + Host‑only  
- Targets: Host‑only  
- AD Lab: Host‑only  
- VulnHub: Host‑only  

## Verify Connectivity
```bash
ip a ip route ping <target> arp -a
```


## Common Issues
- Wrong adapter  
- DHCP not assigning IP  
- Host‑only network disabled

# 5. Reconnaissance Workflows

## Host Discovery
```bash
nmap -sn <network>/24 arp-scan <network>/24 netdiscover
```

## Port Scanning
```bash
nmap -sC -sV -oN scan.txt <IP>
```

## Service Fingerprinting
- Banner grabbing  
- Version detection  
- Script scanning  

## Instructor Note  
Recon is **80% of the job**.  
Exploitation is the easy part.

---

# 6. Enumeration Workflows

## SMB Enumeration
```bash
enum4linux -a <IP> smbclient -L //<IP>/
```

## Web Enumeration
```bash
gobuster dir -u http://<IP> -w /usr/share/wordlists/dirb/common.txt
```

## SSH Enumeration
```bash
ssh -v user@<IP>
```


## Database Enumeration
- MySQL  
- MSSQL  
- PostgreSQL

# 12. Troubleshooting & Common Pitfalls

## Kali Won’t Get an IP
- Check adapter  
- Restart NetworkManager  
- Reboot VM  

## Tools Not Installed
```bash
apt update apt install <tool>
```

## Metasploit Database Errors
```bash
systemctl start postgresql msfdb init
```

## Gobuster Crashes
- Wordlist too large  
- Memory issues
