## System Information
- systeminfo  
  ‣ Display OS version, patches, and system details.
- hostname  
  ‣ Show system hostname.
- wmic os get Caption,Version  
  ‣ Print OS name and version.
- wmic qfe list brief  
  ‣ List installed updates.
- winver  
  ‣ Show Windows version GUI.

## Users & Groups
- net user  
  ‣ List local users.
- net user USERNAME  
  ‣ Show details for a specific user.
- net localgroup  
  ‣ List local groups.
- net localgroup GROUPNAME  
  ‣ Show group members.

## Networking
- ipconfig /all  
  ‣ Display full network configuration.
- netstat -ano  
  ‣ Show ports, connections, and PIDs.
- arp -a  
  ‣ Show ARP table.
- route print  
  ‣ Display routing table.

## Services & Processes
- sc query  
  ‣ List services and their states.
- sc qc SERVICE  
  ‣ Show service configuration.
- tasklist /svc  
  ‣ Show processes with associated services.
- taskkill /PID X /F  
  ‣ Force-kill a process.

## File System & Permissions
- dir /a  
  ‣ List files including hidden/system.
- icacls FILE  
  ‣ Show or modify file ACLs.
- attrib  
  ‣ View or change file attributes.
- tree /f  
  ‣ Display directory structure.

## Logs
- eventvwr.msc  
  ‣ Open Event Viewer.
- wevtutil qe Security  
  ‣ Query Security event log.
- Get-WinEvent -LogName Security  
  ‣ PowerShell event log query.

## PowerShell Essentials
- Get-LocalUser  
  ‣ List local users.
- Get-LocalGroup  
  ‣ List local groups.
- Get-Service  
  ‣ List services.
- Get-Process  
  ‣ List running processes.
- Get-ScheduledTask  
  ‣ List scheduled tasks.
- Get-EventLog -LogName System -Newest 50  
  ‣ Show recent system events.

## Security Checks
- whoami /priv  
  ‣ Show current privileges.
- whoami /groups  
  ‣ Show group memberships.
- net accounts  
  ‣ Show password and lockout policies.
- gpresult /r  
  ‣ Display applied Group Policy settings.
