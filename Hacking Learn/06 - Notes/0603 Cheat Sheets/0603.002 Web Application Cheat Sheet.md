## HTTP Basics
- curl -I URL  
  ‣ Fetch HTTP headers only.
- curl -v URL  
  ‣ Verbose request/response debugging.
- curl -X POST -d "user=admin" URL  
  ‣ Send POST data.
- wget --spider URL  
  ‣ Check if a URL exists without downloading.

## Directory Enumeration
- gobuster dir -u URL -w WORDLIST  
  ‣ Brute-force directories.
- gobuster vhost -u URL -w WORDLIST  
  ‣ Enumerate virtual hosts.
- ffuf -u URL/FUZZ -w WORDLIST  
  ‣ Fast fuzzing for directories/files.

## Header Inspection
- curl -I URL  
  ‣ Inspect server headers.
- curl -s -D - URL  
  ‣ Dump full response headers.

## Authentication Testing
- Check for default creds  
  ‣ Identify weak or unchanged logins.
- Weak lockout policies  
  ‣ Detect brute-force vulnerabilities.
- Predictable session IDs  
  ‣ Identify insecure session generation.

## Input Validation
- SQL injection tests  
  ‣ Identify DB query manipulation.
- XSS tests  
  ‣ Identify client-side script injection.
- Command injection  
  ‣ Detect OS command execution flaws.
- File inclusion  
  ‣ Detect LFI/RFI vulnerabilities.
- Path traversal  
  ‣ Access restricted directories.

## Session Handling
- Inspect cookies  
  ‣ Identify insecure attributes.
- Check HttpOnly  
  ‣ Prevent JS access to cookies.
- Check Secure flag  
  ‣ Ensure HTTPS-only cookies.
- Predictable tokens  
  ‣ Identify weak session entropy.

## Access Control
- Direct object access  
  ‣ Test for IDOR vulnerabilities.
- Role escalation  
  ‣ Attempt privilege bypass.
- Client-side bypass  
  ‣ Identify hidden UI-only restrictions.
