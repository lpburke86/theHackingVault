## Overview
OWASP Broken Web Apps contains dozens of intentionally vulnerable web applications.  
This workbook helps you analyze each one systematically.

- Map each app’s tech stack  
- Document login pages  
- Identify common patterns  
- Identify shared vulnerabilities across apps
