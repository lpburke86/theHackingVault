# 1. Introduction to Metasploitable 3

## What MS3 Is

- A deliberately vulnerable Windows Server 2008 (or Ubuntu) VM
- Designed for exploitation training
- Contains dozens of insecure services
- Mirrors real‑world enterprise systems more closely than MS2

## Why MS3 Matters

- Teaches Windows exploitation
- Builds intuition for AD attacks
- Provides safe, legal practice
- Bridges the gap between MS2 and AD Lab

## What MS3 Is NOT

- Not a modern hardened Windows environment
- Not representative of current enterprise security
- Not a replacement for AD Lab

# 3. Lab Setup & Networking

## Recommended Setup

- Kali: NAT + Host‑only
- MS3: Host‑only

- VulnHub: Host‑only

## Verify Connectivity

```bash
ip a
ping <MS3-IP>
arp -a
```

## Common Issues

- Wrong adapter
- DHCP not assigning IP
- Host‑only network disabled

# 5. Enumeration Workflows

## SMB Enumeration

```bash
enum4linux -a <IP>
smbclient -L //<IP>/
rpcclient -U "" <IP>
```

### What to Look For

- Shares
- Usernames
- Misconfigurations
- Null sessions

---

## WinRM Enumeration

```bash
crackmapexec winrm <IP>
evil-winrm -i <IP> -u <user> -p <pass>
```

### What to Look For

- Cred reuse
- Weak passwords
- Misconfigured policies

---

## RDP Enumeration

```bash
nmap --script rdp-enum-encryption -p 3389 <IP>
```

---

## HTTP Enumeration

```bash
gobuster dir -u http://<IP> -w /usr/share/wordlists/dirb/common.txt
```

### What to Look For

- Jenkins
- Tomcat
- JBoss
- WebDAV
- Upload points

---

## Database Enumeration

- MySQL default creds
- MSSQL weak creds
- phpMyAdmin

# 13. Troubleshooting & Common Pitfalls

## No Shell After Exploit

- Wrong IP
- Firewall
- Wrong payload

## Metasploit Errors

```bash
systemctl start postgresql
msfdb init
```

## WinRM Fails

- Creds wrong
- Service disabled
- Network issue

## Gobuster Crashes

- Wordlist too large
- Memory issues
