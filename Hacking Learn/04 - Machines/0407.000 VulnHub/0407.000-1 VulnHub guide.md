# 0407.000 VulnHub — Machine Index

A centralized index for all VulnHub machines in the lab environment.  
Each machine entry includes:

- Metadata (OS, difficulty, IP, status)
- Links to recon, services, vulnerability matrix, hardening plan
- Notes, flags, credentials
- Attack chain mapping
- Report links
- Workbook integration

This page grows automatically as you add new machines.
