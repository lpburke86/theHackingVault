## 🧪 Lab Tasks

1. Select **three** VulnHub machines (easy → medium → medium‑hard)
2. Perform full recon + enumeration on each
3. Identify foothold vectors (web, SMB, SSH, misconfigurations, etc.)
4. Exploit each machine to gain initial access
5. Perform Linux/Windows PrivEsc as appropriate
6. Capture flags + document full attack chains
7. Save all scans + outputs to your `scans/` folder
