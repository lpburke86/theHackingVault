# 1. Weekly Overview

Week 1 establishes your **entire offensive security workflow**.  
You will configure Kali Linux, learn essential terminal skills, validate your networking environment, and perform your first reconnaissance scans.

This week sets the foundation for every future lab — MS2, MS3, DVWA, Mutillidae, WebGoat, Juice Shop, VulnHub, and the AD Lab.

---

# 2. Learning Objectives

By the end of Week 1, you will be able to:

- Navigate Kali Linux confidently using the terminal
- Configure your networking for multi‑VM lab environments
- Use essential tools: `nmap`, `curl`, `netcat`, `gobuster`, `ssh`
- Perform host discovery and basic recon
- Document findings using your Obsidian templates
- Establish a repeatable workflow for all future labs

# 4. Weekly Labs

### **Lab 1 — Kali Networking Verification**

**Time:** 45 minutes  
**Purpose:** Ensure Kali is correctly configured for Host‑Only + NAT  
**Workbook:** [[0201.000 Kali Workbook]] → Section 3

Commands:

```bash
ip a
ip route
ping <gateway>
ping <other-VM>
```

---

### **Lab 2 — Host Discovery & Recon**

**Time:** 1 hour  
**Purpose:** Learn core recon tools  
**Workbook:** [[0201.000 Kali Workbook]] → Section 5

Commands:

```bash
nmap -sn <network>/24
netdiscover
arp-scan <network>/24
```

---

### **Lab 3 — First Full Port Scan**

**Time:** 1 hour  
**Purpose:** Perform a full TCP scan on MS2  
**Workbook:** [[0202.000 Metasploitable 2 Workbook]] → Section 4

Commands:

```bash
nmap -p- -T4 <MS2-IP> -oN week1_ms2_fullscan.txt
```

### **Assignment 2 — Tooling Deep Dive**

**Time:** 1 hour  
**Template:** [[0501 Machine Analysis Template]]

Requirements:

- Choose one tool (`nmap`, `curl`, `nc`, or `gobuster`)
- Write a 1–2 page analysis including:
    - Purpose
    - Syntax
    - Common flags
    - Example usage
    - When to use it in real pentests
