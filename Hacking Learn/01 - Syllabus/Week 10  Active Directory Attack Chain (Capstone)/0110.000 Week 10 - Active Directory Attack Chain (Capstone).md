## 🧪 Lab Tasks

1. Perform AD recon (`nmap`, SMB, LDAP, Kerberos)
2. Enumerate domain users, groups, SPNs
3. Execute Kerberoasting + crack hashes
4. Execute AS‑REP Roasting + crack hashes
5. Gain foothold on a workstation or server
6. Perform lateral movement (WinRM, SMB exec, WMI exec)
7. Identify PrivEsc path → escalate to Domain Admin
8. Execute DCSync to dump domain secrets
9. Save all commands + outputs to your `scans/` folder
