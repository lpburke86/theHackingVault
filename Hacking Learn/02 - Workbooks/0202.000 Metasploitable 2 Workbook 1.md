# 1. Introduction to Metasploitable 2

## What MS2 Is

- A deliberately vulnerable Linux VM
- Designed for exploitation training
- Contains dozens of insecure services
- Mirrors real‑world legacy systems

## Why MS2 Matters

- Teaches foundational Linux exploitation
- Builds intuition for service enumeration
- Provides safe, legal practice
- Forms the basis for MS3, VulnHub, and AD labs

## What MS2 Is NOT

- Not realistic modern Linux
- Not hardened
- Not representative of modern enterprise security

## Key Services

- vsftpd 2.3.4

- MySQL
- Tomcat
- Samba
- IRC
- RPC

- UnrealIRCd

## Instructor Note

MS2 is intentionally insecure.

# 3. Lab Setup & Networking

## Recommended Setup

- Kali: NAT + Host‑only
- MS2: Host‑only
- AD Lab: Host‑only
- VulnHub: Host‑only

## Verify Connectivity

```bash
ip a
ping <MS2-IP>
arp -a
```

## Common Issues

- Wrong adapter
- DHCP not assigning IP
- Host‑only network disabled

# 4. Reconnaissance Workflows

## Host Discovery

```bash
nmap -sn <network>/24
netdiscover
arp-scan <network>/24
```

## Full Port Scan

```bash
nmap -p- -T4 <IP>
```

## Service Scan

```bash
nmap -sC -sV -oN ms2_scan.txt <IP>
```

## What You Should Identify

- Open ports
- Service versions
- Potential vulnerabilities
- Attack surface

# 5. Enumeration Workflows

## SMB Enumeration

```bash
enum4linux -a <IP>
smbclient -L //<IP>/
```

### What to Look For

- Anonymous access
- Shares
- Usernames
- Misconfigurations

---

## FTP Enumeration

```bash
ftp <IP>
```

### What to Look For

- Anonymous login
- Writable directories
- Banner versions

---

## HTTP Enumeration

```bash
gobuster dir -u http://<IP> -w /usr/share/wordlists/dirb/common.txt
```

### What to Look For

- Web apps
- Upload points
- Admin panels
- Hidden directories

---

## SSH Enumeration

```bash
ssh -v <user>@<IP>
```

### What to Look For

- Banner
- Version
- Auth methods

---

## Database Enumeration

- MySQL default creds
- phpMyAdmin
- Tomcat manager

- Wordlist too large
- Memory issues

- Wrong username
- Service disabled
