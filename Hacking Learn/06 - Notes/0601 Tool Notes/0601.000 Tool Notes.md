# 1. Network & Port Scanning Tools

## [[0601.001 nmap]]
**Purpose:** Network discovery, port scanning, service enumeration.  
**Common Tasks:**  
- Host discovery  
- Full TCP/UDP scans  
- Version detection  
- NSE script usage  

**Quick Commands:**  
- `nmap -sn SUBNET` — Ping sweep  
- `nmap -sV -sC -p- TARGET` — Full scan + scripts  
- `nmap --script vuln TARGET` — Vulnerability scripts  

**Used In:**  
- [[0502 Recon Template]]  
- [[0201.000 Kali Overview of Objectives]]  
- [[0603.004 Enumeration Cheat Sheet]]

# 2. Web Enumeration Tools

## [[0601.002 gobuster]]
**Purpose:** Directory and vhost brute forcing.  
**Quick Commands:**  
- `gobuster dir -u URL -w WORDLIST`  
- `gobuster vhost -u URL -w WORDLIST`  

**Used In:**  
- [[0204.000 DVWA Workbook]]  
- [[0603.002 Web Application Cheat Sheet]]  
- [[0603.004 Enumeration Cheat Sheet]]

## [[0601.005 curl]]
**Purpose:** HTTP requests, debugging, header inspection.  
**Quick Commands:**  
- `curl -I URL` — Headers  
- `curl -v URL` — Verbose  
- `curl -X POST -d "user=admin" URL` — POST data  

**Used In:**  
- [[0204.000 DVWA Workbook]]  
- [[0603.002 Web Application Cheat Sheet]]

# 3. SMB / Windows Enumeration Tools

## [[0601.003 enum4linux]]
**Purpose:** SMB/NetBIOS enumeration.  
**Quick Commands:**  
- `enum4linux TARGET` — Full enumeration  

**Used In:**  
- [[0202.000 Metasploitable 2 Workbook]]  
- [[0206.000 VulnHub Workbook Template]]  
- [[0603.004 Enumeration Cheat Sheet]]

## [[0601.004 smbclient]]
**Purpose:** SMB share access and enumeration.  
**Quick Commands:**  
- `smbclient -L //TARGET/` — List shares  
- `smbclient //TARGET/SHARE` — Connect  

**Used In:**  
- [[0203.000 Metasploitable 3 Workbook]]  
- [[0603.004 Enumeration Cheat Sheet]]

## [[0601.006 rpcclient]]
**Purpose:** RPC enumeration for Windows/SMB.  
**Quick Commands:**  
- `rpcclient -U "" TARGET` — Anonymous RPC  
- `rpcclient -c enumdomusers TARGET` — List users  

**Used In:**  
- [[0207.000 AD Lab Workbook]]  
- [[0603.004 Enumeration Cheat Sheet]]
