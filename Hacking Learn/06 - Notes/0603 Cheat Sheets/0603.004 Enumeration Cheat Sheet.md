## Network Discovery
- nmap -sn SUBNET  
  ‣ Ping sweep to find live hosts.
- arp -a  
  ‣ Show local ARP cache.
- fping -a -g SUBNET  
  ‣ Fast host discovery.

## Port Scanning
- nmap -sV -sC -p- TARGET  
  ‣ Full port scan with version detection and scripts.
- nmap -sU TARGET  
  ‣ UDP port scan.
- nmap --script vuln TARGET  
  ‣ Run vulnerability detection scripts.

## SMB Enumeration
- smbclient -L //TARGET/  
  ‣ List SMB shares.
- smbclient //TARGET/SHARE  
  ‣ Connect to a share.
- enum4linux TARGET  
  ‣ Comprehensive SMB/NetBIOS enumeration.
- rpcclient -U "" TARGET  
  ‣ Query RPC services anonymously.

## HTTP Enumeration
- curl -I URL  
  ‣ Fetch headers.
- gobuster dir -u URL -w WORDLIST  
  ‣ Directory brute-force.
- whatweb URL  
  ‣ Identify web technologies.
- nikto -h URL  
  ‣ Web vulnerability scanner.

## FTP Enumeration
- ftp TARGET  
  ‣ Connect to FTP server.
- Anonymous login test  
  ‣ Check for insecure access.
- Writable directories  
  ‣ Identify upload opportunities.

## SSH Enumeration
- ssh TARGET  
  ‣ Connect to SSH.
- Banner grabbing  
  ‣ Identify SSH version.
- Weak cipher check  
  ‣ Detect insecure configurations.

## SNMP Enumeration
- snmpwalk -v1 -c public TARGET  
  ‣ Enumerate SNMP data.
- snmp-check TARGET  
  ‣ Quick SNMP info gathering.
